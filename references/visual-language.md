# 视听语言转静态画面的规则

## 视点、焦段与透视

摄影机位置决定观察关系：高度、俯仰、左右偏移和与主体的距离会改变遮挡、尺度关系与透视。焦段在机位不变时改变视场；若为了保持相同景别而移动摄影机，透视变化来自机位改变，而不是焦段本身。

因此优先写可见结果：

- 贴近主体的广视场：近处尺度被强调，纵深展开，边缘可能轻微拉伸。
- 远距离窄视场：前后尺度差减弱，背景看起来更接近主体，画面趋于平面化。
- 正面眼平：关系中性、直接、稳定。
- 高机位俯视：暴露地面布局与主体处境；情绪含义由叙事决定。
- 低机位仰视：强调主体与上方空间；不自动等于权威或恐怖。

焦段范围只能作为常见全画幅等效参照，不是跨模型、跨画幅的绝对规则：

| 视场倾向 | 常见参照 | 可见表现 |
|---|---:|---|
| 超广 | 14–24mm | 覆盖大空间、近远尺度差明显、边缘变形风险高 |
| 广角 | 24–35mm | 环境关系强，适合近距离人物与空间同框 |
| 标准 | 35–60mm | 视场自然，几何关系较克制 |
| 中长焦 | 70–135mm | 视场收窄、背景占比增大、利于主体分离 |
| 长焦 | 200mm 以上 | 远距离取景、空间趋平、空气扰动与背景堆叠更明显 |

## 景别与构图

景别描述主体占画面的比例；焦段描述视场，两者不能互相替代。先选景别的叙事功能，再选机位和视场：

- 远景/大全景：环境、尺度、孤立或群体关系。
- 全景：全身动作与场景关系。
- 中景：人物动作、手势与交流。
- 近景：表情和心理距离。
- 特写/大特写：局部证据、材质或高强度情绪。

构图至少确定：视觉中心、主体位置、平衡方式、视线/动作留白、主要线条、遮挡与深度线索。三分法、对称和居中只是可选工具，不是默认答案。

## 空间与视觉结构

用可观察的七类视觉成分检查画面：空间、线条、形状、明暗、色彩、运动暗示、节奏。静态图中的运动通过姿态、衣物方向、重复形和视线延续表现。

“对比”提高视觉强度，“相近”带来统一。对比可以来自大小、形状、明暗、色相、冷暖、清晰度或疏密；不要让每个维度同时高对比，否则画面失去层级。

## 焦点与景深

景深是光圈、焦距、对焦距离、画幅和输出观察共同作用的结果。提示词里优先描述感知结果：焦点落在哪里、前后景清晰到什么程度、背景是可辨识还是化为色块。只有用户需要摄影参数时才补光圈等数值。

## 光线

按以下顺序描述：

1. 来源：太阳、阴天穹顶、窗、软箱、灯泡、霓虹、屏幕、火焰。
2. 方向与高度：侧前、侧后、顶侧、低位、逆光。
3. 尺寸与软硬：大面积包裹、窄束硬光、边缘过渡。
4. 强度关系：主体比背景亮多少，阴影是否保留细节。
5. 颜色：日光、钨丝、冷屏幕光或混合色温。
6. 作用：塑造体积、分离轮廓、突出材质或隐藏信息。

“自然光”仍需说明从哪里来。“电影光”不是可执行描述。

## 色彩与影调

- 色彩：主色、辅色、强调色、冷暖、饱和度与色彩分配。
- 影调：高调/低调、明暗面积、黑位、高光滚降和局部对比。
- 肤色与产品色应作为独立保护项，不能被整体调色污染。

避免无动机的青橙、统一灰雾、全局提清晰度或过度 HDR。若需要胶片质感，写明细颗粒/粗颗粒、反差、色偏、晕光和高光过渡，不必虚构具体胶片库存。
