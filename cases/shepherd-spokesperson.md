# Case：女发言人 / SHEPHARD THE SHEPHERD

## 案例定位

用户提供了一段 15.072 秒、1280×720、24 fps 的 H.264 成片。画面与此前 DiDi_OK《Candy》拆解中的“女发言人”案例一致，因此它被计为该案例的成片验证，不新增案例编号。

原案例是视频镜头提示词；本仓库只提取其中对静态生图有效的视觉规则，不把 zoom out、手持漂移、持续对焦或声音要求混入图片提示词。

## 观察到的成片特征

- 16:9 新闻发布会 / 品牌发布会语境。
- 开场主体是白色 LED 背板上的圆形标志，随后出现重复排列的品牌标志和文字。
- 一名约三十岁女性发言人，头发向后梳起，佩戴小耳钉；画面主要呈现右侧面轮廓。
- 人物位于画面右侧，视线和发言方向朝向左侧场外观众，左侧保留大量背景空间。
- 焦点从背景信息过渡到人物侧脸；人物眼睛、鼻梁、嘴部轮廓是视觉中心。
- 冷白发布会环境光，肤色偏自然暖色；背景高亮、低饱和青绿色标志形成色彩对比。
- 浅景深明显：人物清晰，背景品牌墙柔化但仍能识别其“发布会背板”功能。
- 成片保留轻微纪录片式柔度，没有广告棚拍式硬锐边缘。

## 从视频案例提炼出的静帧规则

1. **构图先于参数**：关键不是填写某个焦段，而是把人物压在画面右侧，让左侧背景承担发布会信息和发言方向。
2. **侧面轮廓需要焦点优先级**：眼睛、鼻梁和嘴部要形成清楚轮廓，耳朵与后脑可以逐渐离焦。
3. **品牌背景要“可识别但不抢人”**：写清重复标志墙的功能、亮度和虚化程度，不要求每一个小字都绝对清晰。
4. **高亮背景仍需肤色分离**：人物不能被白色 LED 背板吞没；用轻微暖肤色和面部局部对比保持主体。
5. **文字风险单独处理**：若品牌拼写必须准确，需要逐字指定并在生成后人工复核；关键商业文字可后期替换。

## 可复用静态图片提示词

```text
【正向提示词】
真人写实的现代品牌发布会新闻摄影，16:9 横幅。画面右侧是一名约三十岁的女性发言人，她将浅棕色头发整齐向后梳起，佩戴小型金色耳钉，身体朝向画面左侧的场外观众，正在发言；摄影机以眼睛高度从她的右侧近距离观察，只呈现清楚的右侧脸轮廓，眼睛、鼻梁和微张的嘴部是唯一视觉中心。人物占据画面右侧约三分之一，左侧保留大面积发布会背景与发言方向的负空间。背景是一块明亮白色 LED 品牌背板，低饱和青绿圆形标志和英文品牌名“SHEPHARD THE SHEPHERD”以规则间距重复排列；背景因浅景深柔和虚化，但仍能辨认发布会语境，不能压过人物。近距离中近景，略带长焦压缩感，焦点准确落在靠近镜头的眼睛与侧脸轮廓，耳朵和背景逐渐柔化。主光来自左前方白色 LED 背板和会场大面积柔光，形成柔和冷白环境；人物肤色保持自然微暖，眼睛有克制高光，面部暗部保留细节。整体冷白、浅灰与低饱和青绿为主，真实皮肤纹理，轻微新闻纪录片质感，柔和高光过渡，不过度锐化，不做商业美妆磨皮。

【负向约束】
不要正脸直视镜头，不要第二名主讲人，不要额外耳饰或变形耳朵，不要蜡像皮肤、磨皮、过度锐化、虚假 HDR、背景完全糊成无意义色块、品牌标志覆盖人物面部、乱码或错误拼写；若“SHEPHARD THE SHEPHERD”用于正式发布，生成后必须人工复核文字。
```

## 不能从该案例普遍化的内容

- “约三十岁”、盘发、小耳钉、白色 LED 背板和青绿色标志只属于这个主题。
- 16:9、侧面近景、浅景深也不是所有发布会画面的固定模板。
- 视频中的镜头移动、对焦变化和现场声音属于视频提示词，不写入静态图片 Skill 的硬规则。
